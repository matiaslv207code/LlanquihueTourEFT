## 📘 Descripción general del sistema
Este proyecto corresponde a la Evaluación Final Transversal de la asignatura *Desarrollo Orientado a Objetos I*. Se trata de un sistema de gestión para **Llanquihue Tour**, desarrollado en Java, cuyo objetivo es modelar y gestionar entidades aplicando de forma práctica los principios de encapsulamiento, composición, herencia, polimorfismo e interfaces.

El sistema permite listar y filtrar de manera dinámica las entidades registrables de la empresa, diferenciando de forma polimórfica entre Clientes y Guías turísticos a través de un menú interactivo en consola.

## 🧱 Estructura general del proyecto

```plaintext
📁 src/
├── app/         # Clase principal (Main) con el menú iterativo
├── model/       # Clases de dominio (Persona, Cliente, Guia, Rut, Direccion)
├── utils/       # Utilidades de lectura (LectorArchivo)

````
